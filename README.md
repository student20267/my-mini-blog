# 💬 Мой мини-блог

Простой мини-блог, написанный на чистом JavaScript. Позволяет добавлять записи, прикреплять к ним картинки и сохранять всё в браузере.

## ✨ Возможности
- Добавление текстовых записей и картинок.
- Сохранение постов в `localStorage` (данные не пропадают после перезагрузки).
- Удаление отдельных постов и очистка всего блога.
- Редактирование заголовка страницы.
- Новые записи отображаются вверху.

## 🚀 Как запустить
Просто откройте файл `index.html` в любом браузере. Никаких установок и зависимостей не нужно.

## 🛠️ Технологии
- HTML5
- CSS3
- JavaScript (Vanilla)
